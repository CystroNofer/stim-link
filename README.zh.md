# StimLink

  

**手柄震动能量微小，配不上您的史诗级游戏操作？**

  

**StimLink** 是一款 Windows 桌面应用程序，可将实时手柄震动转换为受支持的电刺激设备的输出。

本项目目前主要专注于与 **DG-LAB 郊狼 第三代** 进行直接的低功耗蓝牙通信，包括震动记录、波形生成、强度控制、设备通知，以及基于 Dear ImGui 的用户界面。

  

> 本项目仍在积极开发中。接口、行为和协议处理方式均可能发生变化。

  

## 支持的设备

  

### DG-LAB 郊狼 第三代

  

当前后端通过低功耗蓝牙与 郊狼脉冲单元 直接通信。

  

目前已实现的功能包括：

  

* BLE 广播扫描

* GATT 服务与特征发现

* 通过写入特征发送命令

* 通过通知特征接收设备通知

* 持续发送波形数据包

  

---

  

**未来可能会加入更多设备后端**

  

信号缓冲和采样器不会直接生成针对郊狼的数据包。后者返回统一格式的波形数据，再由各个设备后端转换为对应协议的数据格式。
  

## 系统要求

  

* Windows 10 或 Windows 11

* 低功耗蓝牙适配器

* 支持 C++20 的编译器

* Windows SDK

* Visual Studio 2022 或兼容的 MSVC 工具链

* Premake（已包含 Visual Studio 2026 解决方案）

  

## 构建

  

使用 Premake 生成项目文件：

  

```bash

cd  StimLink

premake5  vs2022

```

  

## 使用方法

  

1. 启动应用程序。

2. 在侧边栏中查找附近的蓝牙设备。

3. 从列表中选择任意设备。

  

	> 程序目前只会显示附近的郊狼脉冲单元。
	> 郊狼脉冲单元通常仅显示设备代号。

4. 连接设备。

5. 设置通道强度。

6. 启动支持手柄震动的游戏。

7. 在任何必要时使用紧急停止控制。

  

应用程序会以固定时间间隔对当前信号状态进行采样，并将波形数据发送至设备。

  

对于 Coyote V3，每个波形数据包包含四个 25 ms 的采样值，代表大约 100 ms 的输出。
